# UI 表面原型（popup + 设置页）

Type: prototype
Status: resolved
Blocked by: 10

## Question

"how should it look / behave" 是这个票的问题。用 prototype 技能产出廉价粗糙但可点的原型，供人反应。内容范围：

1. **popup**：当前站点命中哪条规则（命中判定用票 08 已定匹配器；显示规则文本 + 来源：手动/哪台远程源）、一键“保护当前站点”（把当前主机加入手动规则）、总规则数入口、跳设置页。
2. **设置页**：
   - 规则清单管理：搜索、分页/虚拟滚动（10⁴ 条基线）、条目来源标记、手动规则增删改；
   - 批量导入：粘贴 / 本地文件 / 远程 URL 三个入口，导入结果摘要按票 05 已定形态（摘要卡片 + 可展开无效明细）；
   - 远程源管理：源列表（状态、上次成功时间、条数、启用开关、手动刷新、按源授权流程；交互规格按票 07）；
   - 导出当前清单。
3. 文案中文（默认）；交互路径按地图已定约束（导入格式等）。

产出：原型链接或目录挂到本票（资产链到 issue，不粘贴正文）。

- 假数据；演示交互：不记入/恢复记入、权限警告、PIN 锁演示、规则分页、导入摘要展开、源启用开关

## Answer

原型评审会话确认（两轮迭代）：

1. **popup = 单一方案**：当前站点状态 + 一个开关。措辞定为“不记入历史 / 会记入历史 / 设为不记入历史 / 恢复记入历史”（用户否决“保护”“加入清单”等字眼——非拦截工具、清单一词太泛）；不展示“最近命中”（隐私工具不自曝访问）；历史权限缺失时显示提示条。
2. **设置页选定「单列流」**（评审中 A 分区卡片 / B 侧栏应用作废移除）。规则清单**固定每页条数 + 上一页/下一页翻页**（正式版默认每页 50 条，可调），不做无限滚动/加载更多；保留搜索。
3. **PIN 锁（P1–P4 全部采纳）**：只锁设置页（popup 不锁）；4–6 位数字、默认不启用；SHA-256 哈希存 `storage.local`、不存明文、不联网不随账号同步；输错 5 次锁定 30 秒；会话内解锁、重开设置页再要；popup 提供“重置设置”入口（清 PIN 与本地设置/缓存，远程源需重新添加）。

**影响面**：实现会话按此做 Svelte 页面（含分页器组件与 PIN 哈希 + 解锁会话态）。原型文件保留在 `.scratch/sitefade/prototype/ui-prototype.html`（已按最终方案收敛）。地图 fog「设置页展示策略」随本票决议移除。
