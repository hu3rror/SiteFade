# 03: 深色主题（颜色变量组、外观设置、popup 跟随）

**What to build:** 为全部界面表面提供深色外观：颜色变量增加深色取值组（跟随系统外观时自动应用、手动选择时强制覆盖）；修复现有硬编码颜色，保证深色下文字/按钮对比度；设置页新增「外观」区块，提供跟随系统/浅色/深色三态选择；设置新增可选的「主题偏好」字段（默认跟随系统）；popup 启动时按已存偏好应用主题。

**Blocked by:** None（可立即开始；「主题偏好」设置字段由本票自加）

**Status:** ready-for-agent

- [ ] 系统为深色时各界面表面自动深色；手动选「深色/浅色」后覆盖系统外观，重启后保持
- [ ] 设置页「外观」区块提供三态选择并持久化「主题偏好」
- [ ] popup 与设置页均按同一主题偏好渲染（手动深色时 popup 也深色）
- [ ] 深色下文字对比度达标（正文按 WCAG AA），无硬编码浅色残留（含按钮边框、表头背景、按钮文字色等）
- [ ] 存储解码：无主题字段→跟随系统；非法值→兜底；合法值→保留；相关单测通过
